🌷 Админ-панель

Управление письмами для мамы Оли

🔐 Вход администратора

✍️ Новое письмо

Запланированное письмо появится в приложении после наступления выбранного времени, когда мама откроет приложение.

💌 Сохранённые письма

Важно: это автономная админ-панель для одного устройства/браузера. Она не отправляет письма через интернет и не синхронизирует их на телефон автоматически. Для этого позже понадобится настоящий сервер и хостинг.
