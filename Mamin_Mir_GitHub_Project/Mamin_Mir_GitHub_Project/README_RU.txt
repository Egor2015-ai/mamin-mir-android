МАМИН МИР — СБОРКА APK ЧЕРЕЗ GITHUB

1. На GitHub нажми New repository.
2. Назови репозиторий mamin-mir-android. Выбери Public или Private, затем Create repository.
3. На странице пустого репозитория выбери uploading an existing file.
4. Распакуй этот архив и загрузи ВСЕ файлы и папки из него (включая .github; если папка не отображается, включи показ скрытых файлов).
5. Нажми Commit changes.
6. Открой вкладку Actions. Дождись завершения workflow Build Android APK.
7. Открой успешный запуск workflow, внизу раздел Artifacts, скачай Mamin-Mir-debug-apk.
8. Распакуй скачанный artifact ZIP — внутри будет app-debug.apk. Передай APK на Huawei и установи.

ВАЖНО:
- Это тестовая debug-сборка, не публикация в AppGallery.
- APK включает веб-приложение. Онлайн-синхронизация писем пока НЕ настроена.
- Текущая админка хранит данные локально. Пароль, вписанный в HTML, можно увидеть в исходном коде; это не настоящая защищённая авторизация. Не используй такой пароль для других аккаунтов.
- Не публикуй секретные ключи или пароли в GitHub.
